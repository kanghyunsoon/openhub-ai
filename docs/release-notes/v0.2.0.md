# OpenHub AI v0.2.0

OpenHub AI v0.2.0 makes project analysis cover more real project shapes, adds an English desktop interface, and gives you more control over where and for which client a tool is installed. The Verified Registry has **9 tools**. Nothing is installed or changed without a plan you approve, as before.

## Project analysis and recommendations

- New technologies are recognized from project files: Go, Express, NestJS, Jest, Vitest, pytest, Playwright, Unity, Unreal Engine and Kubernetes. Detection uses manifests, dependencies and engine or tool configuration files only; there are no network calls during analysis.
- Two capabilities were added: Kubernetes operations and game engine editor integration. No game engine editor tool is in the Verified Registry yet, so Unity and Unreal Engine projects show this need without a candidate and say why.
- When there are no recommendations, the app explains the reason (for example no recognized stack, no verified tool for the need, or no tool that supports your clients or platform) instead of showing an empty list.
- Recommendations explain why each tool was suggested, and a tool you already use can be added to another client or scope from the same view.

## Verified Registry: 9 tools

v0.2.0 ships with 9 verified tools: Playwright MCP, Chrome DevTools MCP, GitHub MCP Server, Context7, Serena, Postgres MCP and Memory from v0.1.1, plus two new ones:

- **MongoDB MCP Server**, configured read-only with telemetry disabled.
- **Kubernetes MCP Server**, limited to the reviewed version 0.0.67, read-only, with the core toolset and an OpenHub-generated tool configuration that denies reading Secrets. Use it with a least-privilege account: Pod and Node logs it can read may still contain sensitive data.

Every tool passed the same verification criteria as before. A larger Registry is planned for a later release with the same criteria; unverified tools are not added to reach a number.

## Installation and lifecycle

- **Client choice:** choose which clients (Claude Code, Codex, Cursor) a tool is installed for. Each client shows whether OpenHub has verified that it starts the tool on your operating system.
- **Project or user scope:** install for the current project (default) or for your user account (Codex and Cursor). A user-scope install affects every project that uses that client and needs its own approval; the plan shows the exact files that will change.
- **Installed tools by scope:** the Installed view shows project and user installs separately, with status, Health checks and repair for each.
- **Repair:** a missing or changed OpenHub-generated tool configuration, or an invalid client launcher on Windows (for example after Node.js was moved), is detected and can be repaired after you approve a repair plan. OpenHub does not overwrite changes made by others in the meantime.
- **npx packages are prepared before configuration:** exact-version npx packages are downloaded and checked after approval and before any client file is written, so a slow first download no longer makes the Health check time out.
- Installs are decided per target (tool, client, scope and server name), so adding a client or scope later does not touch the existing ones.
- **Update to an exact version (npx tools only):** in the Installed view, a tool installed with npx has an optional target version. Enter an exact version in the form `X.Y.Z` (for example `1.2.3`); ranges, tags such as `latest`, pre-release versions, URLs and paths are rejected before any plan is made. Leave it empty to keep the previous behavior (the Registry's version). The update still needs your approval in the confirmation dialog, which shows the current and target version; the package is prepared before any client file changes, and if the Health check fails, the client configuration and Version State are restored. Kubernetes MCP Server stays limited to its reviewed version 0.0.67.

## Desktop language

- The desktop app is available in English and Korean. On first start it follows your operating system language (Korean for Korean, English otherwise); a language you choose is saved and kept across restarts.
- Approval dialogs and security notices are shown in the selected language. A notice that has no translation yet is shown in its original text and marked as untranslated, never hidden.
- The CLI output is unchanged in this release.

## Compatibility

- No breaking changes to CLI commands, client configuration files, the Registry Manifest format, or the install and lifecycle plan formats. Plans, Version State and settings from v0.1.x remain valid.
- Recommendation reports (`openhub project recommend --json`) now report `taxonomyVersion: 2`; the report `schemaVersion` is still 1. Saved reports from v0.1.x should be regenerated.
- Desktop users without a saved language choice may now see English on first start if their operating system language is not Korean. The language can be changed at any time.

## Known limitations

- **Installing is not the same as a verified start.** Per-client start verification exists for **Kubernetes MCP Server only**; the other 8 tools have no per-client run record. The install plan shows the level for each client and operating system.

  Kubernetes MCP Server, started by the real client from the configuration OpenHub wrote:

  | Client | Windows | Linux | macOS |
  | --- | --- | --- | --- |
  | Claude Code | verified | verified | not verified (platform unverified) |
  | Codex | verified | verified | not verified (platform unverified) |
  | Cursor | not verified | not verified | not verified (platform unverified) |

- **Cursor:** OpenHub writes Cursor configuration, but starting tools from Cursor is **not verified** on any platform.
- **Claude Code:** project scope only; OpenHub does not write the Claude Code user configuration.
- **macOS:** no official artifact and nothing is verified on macOS (platform-unverified). Building from source is not blocked.
- **Kubernetes MCP Server:** only version 0.0.67 is allowed. Other versions are blocked until reviewed.

## Downloads

### Windows x64

Download:

`OpenHub-AI-Setup-0.2.0-x64.exe`

The Windows installer is currently **unsigned**. Windows SmartScreen or Smart App Control may display a warning.

### Linux x64

Download:

`OpenHub-AI-0.2.0-x86_64.AppImage`

### CLI

Download:

`openhub-ai-0.2.0.tgz`

Install it with:

~~~sh
npm install -g ./openhub-ai-0.2.0.tgz
openhub --version
openhub registry list
openhub project scan ./my-project
~~~

Node.js 24.15 or later is required.
