# OpenHub AI v0.1.1

OpenHub AI v0.1.1 is a patch release focused on security hardening and release reliability. It adds no new features and contains no breaking changes.

## Security

- **Fixed a regular expression denial of service (ReDoS) in URL credential detection.** OpenHub detects and redacts `scheme://user:password@` credentials in text it stores or shows. The pattern used for this took time quadratic in the input length, and it is applied to third-party text such as npm `deprecated` messages, npm and PyPI runtime requirements, GitHub release titles and discovery descriptions. In our measurements, a 128 KiB npm `deprecated` message took about 8 seconds to process when checking releases (`openhub release` and the Desktop release view), and the time grew quadratically with longer input. Detection now runs in linear time and returns the same results as before.

## Release reliability

These changes affect how OpenHub AI releases are built and published. They do not change the application itself.

- After uploading, the release workflow reads the GitHub Release back through the GitHub API. It requires all eight release assets to be present exactly once, fully uploaded, and of the expected size, with GitHub digests that match `SHA256SUMS` and the built files.
- The workflow no longer creates a second Release for the same tag. It stops if a published Release or more than one draft already exists, and it reuses a single existing draft when rerun.
- Rerunning the workflow on an existing draft re-uploads the assets only. Release notes already written on the draft are kept.
- A new workflow checks a Release when it is published: required assets, digests against the published `SHA256SUMS`, and a single published Release for the tag.
- User-facing release notes for each version are kept in `docs/release-notes/` and used when the draft Release is created.

## Build and CI

- All build and release scripts are now type-checked in CI. One existing type error was fixed; script behavior is unchanged.

## Compatibility

- No breaking changes. CLI commands, Desktop behavior, configuration files, the Registry format and data schemas are unchanged from v0.1.0.

## Downloads

### Windows x64

Download:

`OpenHub-AI-Setup-0.1.1-x64.exe`

The Windows installer is currently **unsigned**. Windows SmartScreen or Smart App Control may display a warning.

### Linux x64

Download:

`OpenHub-AI-0.1.1-x86_64.AppImage`

### CLI

Download:

`openhub-ai-0.1.1.tgz`

Install it with:

~~~sh
npm install -g ./openhub-ai-0.1.1.tgz
openhub --version
openhub registry list
openhub project scan ./my-project
~~~

Node.js 24.15 or later is required.

## Security and Verification

This release includes:

- `SHA256SUMS` for release artifact integrity
- CycloneDX 1.7 dependency SBOMs
- Windows native/runtime artifact SBOM
- Electron runtime provenance verification
- License and third-party notice validation
- CLI, Windows, and Linux smoke tests

The packaged desktop applications use Electron 44.5.1.
