# Demo project

A small fixture used by `pnpm demo` and the documentation screenshots.

- React web app (`package.json`)
- Spring Boot API (`pom.xml`) with PostgreSQL (`src/main/resources/application.yml`, `docker-compose.yml`)
- Claude Code project configuration (`.mcp.json`) with one MCP server that OpenHub does not manage yet

Database credentials are environment variable references only. Nothing in this folder is executed by the demo.
